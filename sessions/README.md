# Learning Sessions

This directory contains structured learning sessions for mathematics and deep learning.

## Session Structure

Each session should include:
- Learning objectives
- Theory and concepts
- Code examples
- Exercises
- Solutions

## Available Sessions

### Mathematics Sessions
1. **Linear Algebra Basics** - Vectors, matrices, operations
2. **Calculus Fundamentals** - Derivatives, gradients, optimization
3. **Probability & Statistics** - Distributions, hypothesis testing

### Deep Learning Sessions
1. **Neural Networks** - Feedforward networks, backpropagation
2. **CNNs** - Convolutional layers, pooling, image classification
3. **RNNs & LSTM** - Sequence modeling, time series prediction

## How to Use

1. Start with mathematics sessions to build foundational knowledge
2. Progress to deep learning sessions
3. Work through examples and exercises
4. Experiment with modifications to understand concepts better
