# Applied Projects

This directory contains hands-on projects that apply linear algebra and deep learning concepts to real-world problems.

## Available Projects

### Linear Algebra Projects
- **[Applied Linear Algebra Projects](01_applied_linear_algebra_projects.md)** - 6 practical projects:
  1. Image Transformations
  2. Principal Component Analysis (PCA)
  3. Linear Regression from Scratch
  4. Simple Neural Network
  5. Data Preprocessing Pipeline
  6. Face Recognition with Eigenfaces

## How to Use

1. **Read the project description** - Understand the objective and theory
2. **Run the code** - Execute the Python code examples
3. **Study the visualizations** - Analyze the generated graphs
4. **Experiment** - Modify parameters and see what happens
5. **Extend** - Add your own features and improvements

## Prerequisites

- Python 3.8+
- NumPy
- Matplotlib
- Scikit-learn (for some projects)
- PIL/Pillow (for image projects)

Install all dependencies:
```bash
pip install -r requirements.txt
```

After completing these projects, you will:

- Be able to implement algorithms from scratch
- Visualize mathematical concepts
- Apply theory to real problems
- Build confidence in using matrix operations
